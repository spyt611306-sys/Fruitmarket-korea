# 푸릇마켓 Part 48 — 상호 부정행위·피해보호 후보본

Part 32 기준 UI와 Part 46·47의 과일 전문 오픈마켓, 법적 고지, 결제·정산 구조를 유지하면서 판매자·소비자 양방향 부정행위 대응을 추가한 배포 후보본입니다.

## 추가 범위

- 판매자 허위송장·미출고·허위표시·리콜로트·정산계좌 부정변경 탐지
- 소비자 빈상자·상품바꿔치기·허위 미수령·중복환불·차지백·다계정 쿠폰 악용 탐지
- 결제 전 위험검토, 환불 중복차단 및 수동검토, 지급 전 위험검토
- 증거 원본 해시·변경금지, 양측 증거, 택배·중량·로트·온도기록
- 임시조치 종료시각과 자동만료
- 최종 불이익 수동심사·사유기록·통지·이의제기
- 정산계좌 변경 후 72시간 냉각과 MFA 재검증
- 공개 안전거래 정책과 v2 정책 원문 해시

## 시작

1. `DEPLOYMENT-START-HERE.md`
2. `docs/PART48-MUTUAL-PROTECTION.md`
3. `supabase/sql/00_RUN_ORDER.md`
4. `npm install && npm run check`
5. `npm run build`

실제 Supabase·PG·택배사·본인확인·지급대행 계정에서 수행한 라이브 통합시험과 국내 전문가의 법률검토 전에는 결제·정산 활성화를 유지하지 마세요.
