## 외부 공급자 없이는 활성화되지 않는 기능

- Kakao 개발자 앱과 Supabase OAuth 설정
- PASS 또는 본인확인 공급자 API
- 사업자 진위확인 공급자 API
- Toss Payments PG 테스트/라이브 계약
- Toss 지급대행 또는 별도 지급 공급자 계약
- 이메일 SMTP 또는 Supabase Auth 메일 설정

이 항목은 코드를 임의의 성공값으로 처리하지 않으며, 실제 환경변수와 공급자 응답이 없으면 실패하도록 구성했습니다.
