# Part 46 외부 활성화 필수사항

- 실제 프로젝트 생성
- SQL `01~17`을 `00_RUN_ORDER.md` 순서로 실행
- 검증 SQL에서 RLS·함수·게이트·`part46_live_release_ready` 확인
- Storage 버킷 4개와 정책 설정
- Auth Site URL·Redirect URL·SMTP 설정
- Kakao provider 설정
- Edge Functions 8개 배포
- Function Secrets 입력
- 관리자 계정 생성, MFA 등록, 운영자 권한 분리
- 백업·복구와 마이그레이션 롤백 테스트

## Toss Payments·결제보호

- 테스트 상점 client key·secret key
- 결제 성공/실패 URL
- 결제 웹훅 URL
- 승인·전체취소·부분취소·웹훅 재전송 테스트
- 구매안전/에스크로 또는 적용되는 소비자피해보상 구조 확인
- 라이브 계약 승인 후 live key 교체와 소액 재검증

## 판매자 검증·정산

- 본인확인 공급자 endpoint/key
- 사업자 진위확인 endpoint/key
- 지급대행 endpoint/key와 판매자 식별값
- 판매자 정산계좌 암호화 키
- 판매자 계약·수수료·정산·제재 기준 승인
- 정산유보·환불차감·지급실패·대사 절차
- 세금계산서·정산명세·세무 처리 확인
